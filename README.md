## 使用方式

- 左右方向键、空格翻页，Home / End 跳转首末页
- 按 F 全屏，E 静态模式
- 可用浏览器打印导出 PDF

公开版不包含口播稿。背景、品牌标识和字体均内嵌，下载对应的 index.html 后也可以离线演示。

## 武汉大学雷军班 Agent 课程

上午理论课件：72 页 HTML 演示文稿，含「Agent 修 bug」课堂演示视频（6.3 MB）。字体、React 运行时与视频全部以 base64 内嵌，单文件自包含，**断网也可完整放映**。

- [在线课件（72 页，含演示视频）](https://aibuilder-leo.github.io/agentkit-customer-presentation/lei-jun-class/)
- [配套讲义（68 页）](https://aibuilder-leo.github.io/agentkit-customer-presentation/lei-jun-class/notes.html)
- [案例代码 ledger-cli（zip）](https://aibuilder-leo.github.io/agentkit-customer-presentation/lei-jun-class/case-code-ledger-cli.zip)

课件操作方式：

- → / ↓ / PageDown / 空格 翻页，← / ↑ / PageUp 上一页，Home / End 跳转首末页，数字键 1–9 直接跳页
- 按 N 打开目录，按 T 切换明暗，按 F 全屏，按 A 切换动效
- 演示视频页：空格播放 / 暂停，← → 前后 5 秒，Home / End 跳到片头 / 片尾，↑ ↓ 退出视频回到整页
