## 使用方式

- 左右方向键、空格翻页，Home / End 跳转首末页
- 按 F 全屏，E 静态模式
- 可用浏览器打印导出 PDF

公开版不包含口播稿。背景、品牌标识和字体均内嵌，下载 index.html 后也可以离线演示。
