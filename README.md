# AgentKit 客户宣讲

10 页 HTML 演示文稿，V21 口播精简版，沿用正式排版。

逐页口播按约 20 分钟安排（含指图与翻页，不含问答），每页附建议时长和累计时间。技术资料和来源另行折叠，供答疑时参考。

[在线演示](https://aibuilder-leo.github.io/agentkit-customer-presentation/)

## 使用方式

- 左右方向键、空格翻页
- 按 N 查看逐页口播稿，Esc 关闭
- 按 F 全屏，E 静态模式
- 可用浏览器打印导出 PDF

背景、品牌标识和字体均内嵌，下载 index.html 后也可以离线演示。
