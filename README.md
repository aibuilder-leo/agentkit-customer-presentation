## 使用方式

- 左右方向键、空格翻页，Home / End 跳转首末页
- 按 F 全屏，E 静态模式
- 可用浏览器打印导出 PDF

公开版不包含口播稿。背景、品牌标识和字体均内嵌，下载对应的 index.html 后也可以离线演示。

## 更新

产品宣讲位于根目录 `index.html`，客户案例合集位于 `customer-cases/index.html`；分别更新对应文件并推送 main 分支，GitHub Pages 自动更新。
