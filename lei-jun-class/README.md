# 武汉大学雷军班 Agent 课程 · 上午理论

本目录是课程课件的线上版本，内容与本地课程包一致。

| 文件 | 内容 |
|---|---|
| `index.html` | 72 页上午理论课件，内嵌「Agent 修 bug」课堂演示视频（6.3 MB） |
| `notes.html` | 68 页配套讲义，与课件同源 |
| `case-code-ledger-cli.zip` | 课堂案例代码，供学员下载运行 |

## 离线可用

课件把全部字体子集、React 运行时和演示视频以 base64 内嵌在单个 HTML 文件中，
不依赖任何外部脚本或 CDN，**断网环境可以完整放映**。下载 `index.html` 后双击即可本地放映。

## 操作方式

- 翻页：→ / ↓ / PageDown / 空格，← / ↑ / PageUp，Home / End 到首末页，数字键 1–9 跳页
- N 目录，T 明暗切换，F 全屏，A 动效开关
- 演示视频页：空格播放 / 暂停，← → 前后 5 秒，Home / End 跳片头 / 片尾，↑ ↓ 退出视频视图
- 浏览器打印可导出 PDF

## 更新

在本地课程包修改后，覆盖本目录对应文件，提交并推送 main 分支，GitHub Pages 自动更新。
